# books

`* * *`

Bookkeeping, payout reconciliation, and continuous tax readiness for
[DinkusKit](https://github.com/dinkuskit) on
[EmDash](https://github.com/emdash-cms/emdash). Planned package:
`@dinkuskit/books`.

Built for humans and agents to work side by side: store owners operate cleanly
inside EmDash Admin while agents handle routine ingestion, payout splitting,
reconciliation drafts, and tax-readiness checks through CLI and MCP under the
same typed permissions and human approval gates.

## Bootstrap scope under evaluation

- bank, credit-card, statement, and processor-payout reconciliation;
- cash and accrual financial statements (Profit & Loss, Balance Sheet, Trial
  Balance, General Ledger exports);
- post-checkout monthly sales-tax liability isolation, nexus watch, and
  exemption tracking;
- year-round federal and state estimated income-tax reserve tracking;
- contractor (`1099`) and payroll (`W-2`) accounting boundaries.

## Status

Public design stub (`0.0.0`, `private: true`). There is no installable plugin
or published npm package yet. Product specifics are being researched and locked
via GrillTrack before implementation begins.

Under construction, dogfooding in the open. MIT.
